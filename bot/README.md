# Спред-бот MEXC Futures ↔ Binance

Python-бот для VPS/ПК: ищет спред между ценой фьючерса на MEXC и референсной ценой Binance,
открывает сделки на фьючерсах MEXC только по парам с 0% комиссией, с максимальным плечом
и контролируемым риском (стоп = заданный % от депозита). Управление и уведомления — через Telegram.

## Как это работает

1. Раз в час бот собирает список пар: zero-fee на вашем аккаунте MEXC + пара существует
   на Binance (фьючерсы или спот) + 24ч объём ≥ 500k$.
2. Каждые ~2 сек сравнивает mid-цену MEXC (тикер/стакан) с mid-ценой Binance.
3. Спред ≥ порога (дефолт 0.3%) и держится 2 скана подряд → вход по рынку:
   - MEXC дешевле Binance → **LONG**, дороже → **SHORT**.
4. Размер позиции: маржа = 20% депо (настраивается) × макс. плечо пары, изолированная маржа.
   **Стоп считается от депозита**: при срабатывании теряется ровно `stop_loss_pct` % депо
   (дефолт 5%), а не весь депозит. Если стоп получается слишком близко к цене — бот сам
   уменьшает нотионал/плечо. SL/TP ставятся на бирже + дублируются программно.
5. Тейк — по схождению спреда (дефолт до 0.05%). Перед входом проверяется, что ожидаемый
   профит ≥ 0.3% депо с учётом проскальзывания — «почти убыточные» сделки отсекаются.
   Если спред не сошёлся за 15 мин — закрытие по рынку.
6. Одна позиция за раз; после закрытия — случайная пауза 30–120 сек.
7. После каждого флипа в Telegram приходит отчёт: `BTC_USDT | SHORT | +0.42% к депо / +2.13$`.

## Установка

Нужен Python 3.10+.

```bash
cd bot
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env            # и заполните .env
python main.py
```

## Настройка .env

### 1. MEXC API key
mexc.com → Профиль → API Management → создать ключ с правами:
- Account: View Account Details
- Trade: View Order Details + Order Placing

Используется для чтения баланса/позиций и попытки выставления ордеров.

### 2. MEXC WEB-токен (важно!)
Официальный эндпоинт открытия фьючерсных ордеров у MEXC уже давно возвращает
"maintenance" — несмотря на галочку Order Placing. Рабочий способ — WEB-токен:

1. Войдите на **futures.mexc.com** в браузере.
2. F12 → вкладка **Application** (Chrome) / **Storage** (Firefox) → **Cookies** → `https://futures.mexc.com`.
3. Найдите cookie **`u_id`** — значение начинается с `WEB...`.
4. Вставьте его целиком в `MEXC_WEB_TOKEN`.

Токен живёт, пока жива сессия браузера (не выходите из аккаунта). Если протух —
бот напишет об этом в Telegram, обновите значение и перезапустите бота.

### 3. Telegram
1. В Telegram найдите **@BotFather** → `/newbot` → получите токен → `TELEGRAM_BOT_TOKEN`.
2. Узнайте свой ID у **@userinfobot** → `TELEGRAM_ADMIN_ID`.
3. Напишите своему боту `/start` (иначе он не сможет отправлять вам сообщения).

## Команды Telegram

| Команда | Действие |
|---|---|
| `/status` | Состояние + инлайн-кнопки управления |
| `/start_trading` / `/stop_trading` | Запуск / пауза торговли |
| `/balance` | Баланс с биржи |
| `/risk 3` | Терять при стопе 3% депозита |
| `/spread 0.4` | Порог входа 0.4% |
| `/size 15` | Маржа на сделку 15% депозита |
| `/cooldown 60 180` | Пауза между сделками 60–180 сек |
| `/pairs` | Текущий список zero-fee пар |
| `/stats` | Статистика и последние сделки |
| `/close` | Принудительно закрыть позицию |

## Запуск 24/7 на VPS (systemd)

`/etc/systemd/system/spreadbot.service`:

```ini
[Unit]
Description=MEXC spread bot
After=network-online.target

[Service]
WorkingDirectory=/opt/spreadbot/bot
ExecStart=/opt/spreadbot/bot/venv/bin/python main.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now spreadbot
journalctl -u spreadbot -f      # логи
```

Альтернатива: `screen -S bot python main.py` или pm2 (`pm2 start main.py --interpreter python3`).

## Файлы

- `bot.log` — лог-файл.

## ⚠️ Дисклеймер

- WEB-токен — неофициальный метод (внутренние эндпоинты биржи). MEXC может изменить
  подпись/эндпоинты в любой момент; токен периодически протухает.
- Торговля с максимальным плечом несёт высокий риск. Бот ограничивает убыток при стопе,
  но проскальзывание на неликвидных парах, гэпы и сбои биржи могут увеличить фактический
  убыток. Начинайте с малого депозита и `/risk 1`.
- Zero-fee список зависит от аккаунта; комиссия для API-ордеров может отличаться от
  комиссий в веб-интерфейсе — проверьте первую сделку вручную.
